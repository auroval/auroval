Every turn drew a frame before; none does now. The loop still wakes about
63 times a second — deliberately, because greetd's conversation arrives on
a channel calloop knows nothing about, so `pump_auth` is only as prompt as
that timeout. Waking is a string compare; drawing was a 2560x1440 frame.

The two frames in the first second are the first frame and the configure
that follows it. The frame dump proves they are one picture: the same run
with AUROVAL_FRAME_DUMP set drew 2 frames and wrote exactly 1 PNG
(1280x720 RGBA), which is what the dump's own dedupe is still there for.
